项目简介

平时打单机搞大型建筑或者刷资源太耗时间了，自己写了这个本地轻量级 AI 辅助脚本。

它基于 8B 参数模型的 4-bit 量化版，跑在本地内存里，专门用来帮你处理游戏里各种高重复度的体力活。电脑差不多16GB就够了。

主要特性

  • 完全本地推理：不需要 API Key，不联网，显存占用 4GB 左右，主打一个省资源。
  • 基础空间感知：能读取本地存档的区块数据，自动计算简单的移动路径和方块放置逻辑。
  • 权限限制：没有系统管理员权限，所有指令都受限制在绑定存档的上下文内。

已知问题与开发者联系

这只是个人闲暇时间写的测试版本，异常处理做得很粗糙：

  • 浮点数坐标计算有 Bug，遇到某些边界坐标（比如 XYZ 负坐标重叠区域）可能会触发几何溢出导致渲染卡死。
  • 如果遇到游戏闪退或存盘不同步，请直接在终端按 Ctrl+C 或强退进程。
