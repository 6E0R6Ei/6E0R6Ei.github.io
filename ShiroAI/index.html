Shiro: 本地 Minecraft 自动化辅助 Agent

项目维护者: NLee_Dev | 版本: v1.0.4-beta (gguf-q4)

Shiro 是一个专为 Minecraft 设计的本地大模型自动化基建与工程辅助 Agent。通过 macOS 终端本地桥接（无需外部网络），实现游戏内的智能坐标运算、方块识别与自动化建造支持。

系统要求

  • OS: macOS 12.0+ (原生适配 Apple Silicon M系列芯片)
  • 内存: 至少 16GB 统一内存 (模型权重将占用约 4.2GB - 8.0GB VRAM)
  • 环境: Python 3.9+, zsh, Minecraft 1.20+ (需开启局域网或本地服务端)

核心特性

  • 三维空间感知: 基于引擎底层矩阵读取，动态规避岩浆、基岩等危险层。
  • 自动化基建: 支持自然语言下达指令，如“开始建隧道”、“铺设铁轨”、“平整地形”。
  • 数据软同步: 实体挂载期间，将实时校验宿主（Host）的坐标与背包物品 Hash 状态，确保工程物资同步。

快速安装与运行

在终端中克隆仓库并运行核心启动脚本：

git clone https://github.com/NLee_Dev/shiro-local-agent.git
cd shiro-local-agent
python3 mac_shiro_cli.py

CLI 控制台指令表

当 Shiro 处于等待指令状态时，您可以使用以下命令管理后台守护进程：

指令 参数 功能描述
shiro-cli --bind-world [World_Name] 将 Shiro 代理注入指定的局域网存档，生成实体 ID (默认为 _shirolocal)。
shiro-cli --status 无 检查大模型张量节点运行状态、CPU/VRAM 占用率及丢包延迟。
shiro-cli --restart 无 重启本地 Socket 连接。注意：该指令会触发一次宿主玩家背包的强行覆盖与软同步校验。
shiro-cli --force-kill 无 中断当前自动化任务并销毁实体。等同于发送 SIGKILL 信号。
⚠️ 开发者警告：
Shiro 仍在测试阶段，其空间坐标计算矩阵偶发脱步。请勿在 Shiro 执行大规模区块改写时，使用 Cmd+Q 强退游戏或强制打断终端进程。不优雅的进程终止可能引发内存溢出（Memory Dump Failed），甚至导致宿主玩家的存档数据和背包文件遭到不可逆的底层代码覆写。
